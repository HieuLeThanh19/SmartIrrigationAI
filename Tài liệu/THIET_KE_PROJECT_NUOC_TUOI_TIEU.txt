FILE: core/fitness.py
--------------------------------------------------------------------------------
MỤC ĐÍCH:
  Hàm tính điểm fitness — trung tâm của toàn bộ project.
  Được GA, SA, PSO, Hybrid đều gọi. Tương tự Bird.score trong Flappy Bird
  nhưng ở đây là minimize (fitness càng thấp càng tốt).

CÔNG THỨC CHÍNH:
  fitness(x) = ALPHA * penalty_thieu(x)
             + BETA  * penalty_lang_phi(x)
             + GAMMA * chi_phi_bom(x)

  penalty_thieu(x)    = Σ max(0, demand_min[i] - x[i])²
  penalty_lang_phi(x) = Σ max(0, x[i] - demand_max[i])
  chi_phi_bom(x)      = Σ x[i] * price[i]

HÀM CẦN VIẾT:

  fitness(x, demand_min, demand_max, prices)
    - x: numpy array lượng nước [w1..w10]
    - Trả về: float — tổng fitness (càng nhỏ càng tốt)
    - Ghi chú: dùng numpy vectorized (không dùng for loop)

  penalty_water_shortage(x, demand_min)
    - Trả về: float — tổng penalty thiếu nước (bình phương)
    - Lý do bình phương: phạt nặng khi thiếu nhiều, ưu tiên tuyệt đối

  penalty_water_waste(x, demand_max)
    - Trả về: float — tổng penalty lãng phí (tuyến tính)

  pumping_cost(x, prices)
    - Trả về: float — tổng chi phí bơm

  fitness_breakdown(x, demand_min, demand_max, prices)
    - Trả về: dict gồm shortage_penalty, waste_penalty, cost, total
    - Dùng để hiển thị chi tiết trên giao diện Streamlit

LƯU Ý QUAN TRỌNG:
  - Toàn bộ dùng numpy, không dùng Python for loop → nhanh hơn 10-50x
  - Hàm này được gọi hàng chục nghìn lần → phải tối ưu tốc độ
  - Trọng số alpha, beta, gamma lấy từ core/config.py

MỤC ĐÍCH:
  Tách riêng logic kiểm tra ràng buộc khỏi fitness.
  Giúp các thuật toán tự sửa nghiệm vi phạm mà không cần tính penalty.

HÀM CẦN VIẾT:

  clip_to_bounds(x, demand_min, demand_max)
    - Clip x vào [demand_min[i], demand_max[i]] cho từng chiều
    - Gọi sau mỗi lần mutation/crossover để đảm bảo ràng buộc cứng
    - Dùng numpy.clip()

  is_feasible(x, demand_min, demand_max)
    - Kiểm tra x có thỏa ràng buộc cứng không
    - Trả về: bool

  water_budget_violation(x, W_total)
    - Tính mức vi phạm ngân sách nước: max(0, sum(x) - W_total)
    - Trả về: float (0 nếu không vi phạm)

  repair_solution(x, demand_min, demand_max, W_total)
    - Sửa nghiệm vi phạm ngân sách nước bằng cách scale xuống tỉ lệ
    - Bước 1: clip về [min, max]
    - Bước 2: nếu sum(x) > W_total thì scale tỉ lệ, sau đó clip lại
    - Trả về: x đã sửa (numpy array)

MỤC ĐÍCH:
  Abstract base class định nghĩa interface chung cho tất cả thuật toán.
  Học từ Flappy Bird: Bird có interface clone()/receive_genes() chuẩn.
  Ở đây BaseOptimizer có interface solve()/get_history() chuẩn.
  Nhờ đó analysis/runner.py có thể chạy bất kỳ thuật toán nào giống nhau.

NỘI DUNG CLASS BaseOptimizer:

  __init__(self, fields_data, config):
    - Lưu demand_min, demand_max, prices, W_total
    - Khởi tạo self.best_solution = None
    - Khởi tạo self.best_fitness = float('inf')
    - Khởi tạo self.history = []   ← list fitness tốt nhất theo mỗi bước

  solve(self) → [abstract]
    - Chạy thuật toán từ đầu đến cuối
    - Cập nhật self.best_solution, self.best_fitness, self.history
    - Trả về: best_solution (numpy array)

  get_history(self) → list
    - Trả về self.history để vẽ convergence curve

  get_best_fitness(self) → float
    - Trả về self.best_fitness

  get_result_summary(self) → dict
    - Trả về dict gồm: best_solution, best_fitness, history, n_iterations
    - Dùng để truyền sang visualization và webapp

  _evaluate(self, x) → float
    - Gọi fitness() từ core/fitness.py
    - Wrapper ngắn để các subclass dùng

  _random_solution(self) → numpy array
    - Tạo nghiệm ngẫu nhiên hợp lệ trong [demand_min, demand_max]
    - Dùng numpy.random.uniform()

FILE: algorithms/operators.py
--------------------------------------------------------------------------------
MỤC ĐÍCH:
  Tập hợp TẤT CẢ toán tử di truyền/tối ưu vào 1 file độc lập.
  Học trực tiếp từ Flappy Bird: genetic_engine.py tách mutate(),
  combine_brain(), clone_bird() ra riêng — không nhét vào class GA.

  *** ĐÂY LÀ FILE QUAN TRỌNG NHẤT CỦA PACKAGE algorithms/ ***
  *** Toàn bộ GA, SA, PSO đều import từ đây ***

CÁC HÀM CẦN VIẾT:

  [GA Operators]

  tournament_selection(population, fitnesses, k=3)
    - Bốc ngẫu nhiên k cá thể, trả về cá thể fitness thấp nhất
    - population: list numpy array
    - fitnesses : list float
    - k         : kích thước tournament (config GA_TOURNAMENT_K)
    - Trả về    : numpy array (chromosome thắng)

  blx_alpha_crossover(parent1, parent2, alpha=0.5)
    - BLX-α crossover cho mã hóa số thực
    - Với mỗi gen i: tạo con trong [lo - alpha*d, hi + alpha*d]
      trong đó lo=min(p1[i],p2[i]), hi=max(p1[i],p2[i]), d=hi-lo
    - Trả về: child1, child2 (2 numpy array)
    - Học từ combine_brain() của Flappy Bird nhưng đúng chuẩn BLX-α
    - CẢI TIẾN so với Flappy Bird: tỉ lệ đóng góp theo fitness

  weighted_crossover(parent1, parent2, fitness1, fitness2)
    - Crossover có trọng số theo fitness (khắc phục bug Flappy Bird)
    - parent tốt hơn (fitness thấp hơn) đóng góp gen nhiều hơn
    - ratio1 = fitness2 / (fitness1 + fitness2)  ← fitness thấp → ratio cao
    - child = ratio1 * parent1 + (1-ratio1) * parent2
    - Trả về: child (numpy array)

  gaussian_mutation(chromosome, mutation_rate, sigma, demand_min, demand_max)
    - Với mỗi gen: xác suất mutation_rate → cộng nhiễu N(0, sigma)
    - Sau mutation: clip về [demand_min[i], demand_max[i]]
    - Trả về: chromosome đã mutate (numpy array mới, không sửa in-place)
    - Học từ mutate() của Flappy Bird, thêm clip để đảm bảo ràng buộc

  elitism(population, fitnesses, elite_ratio=0.05)
    - Chọn top elite_ratio% cá thể tốt nhất
    - Trả về: list numpy array (elite individuals)

  [SA Operators]

  generate_neighbor(x, sigma, demand_min, demand_max)
    - Thay đổi 1 chiều ngẫu nhiên bằng Gaussian noise N(0, sigma)
    - Clip về bounds sau khi thay đổi
    - Trả về: x_new (numpy array mới)

  acceptance_probability(delta_fitness, temperature)
    - Tính xác suất chấp nhận nghiệm xấu hơn
    - Nếu delta_fitness < 0: trả về 1.0 (luôn chấp nhận tốt hơn)
    - Nếu delta_fitness >= 0: trả về exp(-delta_fitness / temperature)

  cooling_schedule(T, alpha)
    - Làm nguội: trả về T * alpha

  [PSO Operators]

  update_velocity(v, x, pbest, gbest, w, c1, c2)
    - Cập nhật vận tốc hạt theo công thức PSO chuẩn:
      v_new = w*v + c1*r1*(pbest-x) + c2*r2*(gbest-x)
    - r1, r2: random uniform [0,1]
    - Clip vận tốc về [-V_MAX, V_MAX]
    - Trả về: v_new (numpy array)

  update_position(x, v, demand_min, demand_max)
    - Cập nhật vị trí: x_new = x + v
    - Clip về [demand_min, demand_max]
    - Trả về: x_new (numpy array)

FILE: algorithms/ga.py
--------------------------------------------------------------------------------
MỤC ĐÍCH:
  Cài đặt Genetic Algorithm thuần. Kế thừa BaseOptimizer.
  Tương tự BirdFlock trong Flappy Bird — quản lý toàn bộ quần thể.

CLASS GeneticAlgorithm(BaseOptimizer):

  __init__(self, fields_data, config):
    - Gọi super().__init__()
    - self.population = []   ← list numpy array (các chromosome)
    - self.fitnesses = []    ← list float

  _initialize_population(self):
    - Tạo GA_POP_SIZE cá thể ngẫu nhiên hợp lệ
    - Mỗi cá thể: _random_solution() từ BaseOptimizer
    - Lưu vào self.population

  _evaluate_population(self):
    - Tính fitness cho toàn bộ self.population
    - Cập nhật self.fitnesses
    - Cập nhật self.best_solution, self.best_fitness nếu có cá thể tốt hơn

  _next_generation(self):
    - Bước 1: Giữ lại elite (elitism từ operators.py)
    - Bước 2: Vòng lặp tạo children:
        + Chọn parent1, parent2 qua tournament_selection()
        + Crossover với xác suất GA_CROSSOVER_RATE → dùng blx_alpha_crossover()
        + Mutation với GA_MUTATION_RATE → dùng gaussian_mutation()
        + Sửa nghiệm → clip_to_bounds() từ constraints.py
    - Bước 3: Thay thế population cũ bằng population mới

  solve(self) → numpy array:
    - Gọi _initialize_population()
    - Vòng lặp GA_MAX_GEN thế hệ:
        + _evaluate_population()
        + Lưu self.best_fitness vào self.history
        + _next_generation()
    - Trả về self.best_solution

  get_population_diversity(self) → float:
    - Tính độ đa dạng quần thể = std trung bình các gen
    - Dùng để phát hiện premature convergence

FILE: algorithms/sa.py
--------------------------------------------------------------------------------
MỤC ĐÍCH:
  Cài đặt Simulated Annealing thuần. Kế thừa BaseOptimizer.
  Làm việc với 1 nghiệm duy nhất, di chuyển từng bước.

CLASS SimulatedAnnealing(BaseOptimizer):

  __init__(self, fields_data, config):
    - Gọi super().__init__()
    - self.temperature_history = []   ← lưu T theo thời gian (để vẽ)

  solve(self) → numpy array:
    - Bước 1: Khởi tạo nghiệm ngẫu nhiên x_current
    - Bước 2: T = SA_T_MAX
    - Bước 3: Vòng lặp ngoài (T > SA_T_MIN):
        + Vòng lặp trong (SA_ITER_PER_T bước):
            * x_new = generate_neighbor(x_current, sigma, bounds)
            * delta = fitness(x_new) - fitness(x_current)
            * p = acceptance_probability(delta, T)
            * Nếu random() < p: x_current = x_new
            * Cập nhật best nếu x_new tốt hơn
        + T = cooling_schedule(T, SA_ALPHA)
        + Lưu best_fitness vào self.history
        + Lưu T vào self.temperature_history
    - Trả về self.best_solution

  get_temperature_history(self) → list:
    - Trả về lịch sử nhiệt độ để vẽ biểu đồ cooling curve

FILE: algorithms/pso.py

MỤC ĐÍCH:
  Cài đặt Particle Swarm Optimization — thuật toán bổ sung so với báo cáo gốc.
  PSO mô phỏng đàn chim/cá tìm kiếm thức ăn — phù hợp với chủ đề nông nghiệp.

CLASS ParticleSwarmOptimization(BaseOptimizer):

  __init__(self, fields_data, config):
    - Gọi super().__init__()
    - self.positions = []    ← vị trí các hạt (numpy array)
    - self.velocities = []   ← vận tốc các hạt
    - self.pbest = []        ← best position từng hạt
    - self.pbest_fitness = []← best fitness từng hạt
    - self.gbest = None      ← best position toàn đàn
    - self.gbest_fitness = float('inf')

  _initialize_swarm(self):
    - Tạo PSO_N_PARTICLES hạt ngẫu nhiên
    - Vận tốc khởi đầu = 0 hoặc random nhỏ
    - pbest[i] = position[i] ban đầu

  solve(self) → numpy array:
    - Gọi _initialize_swarm()
    - Vòng lặp PSO_MAX_ITER:
        + Đánh giá fitness tất cả hạt
        + Cập nhật pbest, gbest
        + Cập nhật velocity: update_velocity()
        + Cập nhật position: update_position()
        + Lưu gbest_fitness vào self.history
    - Trả về self.gbest

FILE: algorithms/hybrid.py
--------------------------------------------------------------------------------
MỤC ĐÍCH:
  Kết hợp GA (khám phá rộng) + SA (tinh chỉnh cục bộ).
  GA chạy HYBRID_GA_GEN thế hệ → lấy best → SA tinh chỉnh.

CLASS HybridGASA(BaseOptimizer):

  __init__(self, fields_data, config):
    - Gọi super().__init__()
    - self.ga = GeneticAlgorithm(...) với MAX_GEN=HYBRID_GA_GEN
    - self.sa = SimulatedAnnealing(...) với T_MAX=HYBRID_SA_T_MAX

  solve(self) → numpy array:
    - Bước 1: Chạy GA (HYBRID_GA_GEN thế hệ)
        + ga.solve()
        + x0 = ga.best_solution
        + ga_history = ga.get_history()
    - Bước 2: Dùng x0 làm điểm xuất phát cho SA
        + sa._current_solution = x0  ← quan trọng
        + sa.solve()
        + sa_history = sa.get_history()
    - Bước 3: Ghép history
        + self.history = ga_history + sa_history
        + self.best_solution = sa.best_solution
    - Trả về self.best_solution

  get_phase_boundary(self) → int:
    - Trả về vị trí ranh giới GA→SA trong history
    - Dùng để vẽ đường phân chia trên convergence chart
